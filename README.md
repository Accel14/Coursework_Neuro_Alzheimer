# Разработка системы диагностики нейродегенеративных заболеваний на основе анализа поведения пользователя в виртуальной среде



## Описание проекта



Курсовой проект посвящён разработке системы оценки когнитивных функций пользователя с использованием виртуальной среды и анализа электроэнцефалографических (ЭЭГ) данных.



Проект объединяет два основных компонента:



1. **Unity-приложение** — виртуальная среда с интерактивными заданиями, в которой пользователь выполняет действия, связанные с выбором товаров в виртуальном магазине.

2. **Модуль анализа ЭЭГ** — Python-приложение для обработки ЭЭГ-данных и классификации с использованием модели машинного обучения.



## Структура проекта



- `UnityProject/` — проект виртуальной среды на Unity.

- `EEG\_Analysis/` — обработка ЭЭГ-данных, обучение модели и API.

- `Documentation/` — документация и материалы курсовой работы.

## Запуск Python API



Перейдите в папку `EEG\_Analysis` и установите зависимости:



```bash

pip install -r requirements.txt

```



Запустите API:



```bash

python -m uvicorn eeg\_api:app --host 127.0.0.1 --port 8000

```



После запуска документация API доступна по адресу:



`http://127.0.0.1:8000/docs`



## Обучение модели



Для повторного обучения модели используется скрипт `model\_train.py`.



Для его работы необходим исходный датасет, расположенный в папке `EEG\_Analysis/dataset/` в соответствии с ожидаемой структурой.

Проект является исследовательской разработкой в рамках курсовой работы. Результаты классификации не предназначены для самостоятельной постановки медицинского диагноза и не заменяют клиническое обследование.
